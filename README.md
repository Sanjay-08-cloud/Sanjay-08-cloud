### About

Final-year B.E. Computer Science student focused on AI/ML engineering, with hands-on experience building and shipping full ML systems end-to-end — not just models in a notebook. Completed an AI/ML internship at **Pydun Innovate Technologies**, and currently building **Project Compass**, a retrieval-augmented system engineered around a simple principle: an answer is only worth giving if it's genuinely grounded in a source.

#### 🧠 [Project Compass](https://github.com/Sanjay-08-cloud/Project_Compass)

A secure, self-hosted RAG assistant for organizations. Hybrid FAISS + BM25 retrieval fused via **Reciprocal Rank Fusion**, cross-encoder reranking, and a hard refusal gate ensure answers are generated only when genuinely supported by the source documents — with full local inference via Qwen 2.5 on Ollama.
